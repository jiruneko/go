## 囲碁アプリ（9路）vs COM

ブラウザ上で動作する、軽量・インストール不要の囲碁アプリです。
Canvas + 純JavaScriptで実装しており、人間（黒） vs COM（白） の対戦が可能です。

オセロアプリと同様に、

読み込みが速い

操作が直感的

学習・デモ・居場所系アプリへの組み込みを想定

した設計になっています。

🎮 概要

対応ルール

石の取り（アタリ）

自殺手禁止

簡易コウ対応

両者連続パスで終局

コミ：6.5（白）

盤サイズ

9路（推奨・軽量）

13路（やや重め）

プレイヤー

あなた：黒

COM：白

🧠 COM（AI）の特徴

難易度は3段階です。

難易度	内容
やさしい	ランダム寄り・たまに取り
ふつう	取り優先＋簡易評価
ちょい強	1手読み（ミニマックス風）

※ 本格囲碁AIではありませんが、
「考えて打っている感覚」は十分あります。

🖱 操作方法
操作	内容
クリック	石を置く
Pキー / パスボタン	パス
Rキー	リセット
1手戻す	直前の手を取り消し
投了	即終了
📊 表示される情報

現在の手番

手数

連続パス数

黒・白の捕獲数

推定スコア（地 + 石 + 捕獲 + コミ）

※ スコアはあくまで簡易推定です
（正式な死活判定は行いません）

🧱 技術構成

HTML5

CSS（UIは完全自作）

JavaScript（フレームワーク不使用）

Canvas描画

外部ライブラリ：なし
